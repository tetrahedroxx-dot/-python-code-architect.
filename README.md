# ⚡ Python Code Architect & Automated Debugger

An AI-powered web application that automatically performs static analysis, logic evaluation, security patching, and PEP 8 refactoring on broken Python scripts.

## ✨ Features
- **Static Analysis:** Identifies syntax errors, typos, missing imports, and scope issues.
- **Logic Evaluation:** Corrects control flow errors, loop bugs, and type mismatches.
- **Security & Error Handling:** Implements `try-except` blocks and patches vulnerable code patterns.
- **PEP 8 Refactoring:** Cleans code formatting and optimizes performance while maintaining core logic.
